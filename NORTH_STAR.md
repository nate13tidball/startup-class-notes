# North Star

## Goal

Make startup business class notes easy to browse by topic, with clear links and attribution to each original class. The repository should be useful beyond any one program while preserving the context of its sources.

## Scope

Include notes, transcripts, slides, and source indexes relevant to starting and building a business. Keep source-specific material identifiable and link back to the original publisher. Exclude personal profiles, credentials, and private interaction data. This is an independent study collection, not an official course publication.

## Implemented

The repository currently contains an archive of public Fifty Years 50/50 C9 material: topic links, recording transcripts, slide decks, extracted slide text, source-page records, and scripts to refresh them. The original publisher and video links remain in the source indexes. The C9 Humans directory is ignored by Git.

## Validated

The initial archive was pushed to a public GitHub repository, and its 53 committed JSON files parsed successfully in November 2026. These checks establish file integrity and publication, not the accuracy of transcript or OCR content.

## Open gaps

Most material is archived source text rather than original synthesized class notes. Other startup courses have not yet been added.
